# Agentic To-Do App

A single-page FastAPI to-do app with SQLite persistence, plain REST CRUD, natural-language task commands, next-task recommendations, and daily summaries. Agents access task data only through tool functions in `tools/repository.py`.

## Requirements

- Python 3.11 or newer in the Python 3.11 series
- No LLM API key is needed for the rule-based fallback

## Install

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
```

PowerShell activation: `.\.venv\Scripts\Activate.ps1`.

## Run

Set `PORT` in the environment, then run the requested command:

```sh
export PORT=8000
uvicorn main:app --host 0.0.0.0 --port $PORT
```

In PowerShell:

```powershell
$env:PORT = "8000"
uvicorn main:app --host 0.0.0.0 --port $env:PORT
```

Open <http://localhost:8000/>. SQLite is stored in `tasks.sqlite3` beside `main.py` by default; set `TODO_DATABASE` to override the path. Set `OPENAI_API_KEY` to enable OpenAI-backed interpretation. Without it, supported task commands, planning, and summaries use deterministic rules. Provider errors also fall back safely; uncertain commands request clarification rather than applying a write.

## Test

```sh
python -m pytest
```

Tests use temporary SQLite databases and mocked provider behavior; no live API key or provider call is required. The app is single-user and does not include authentication or task sharing.

## API

Task CRUD is available under `/api/tasks`; natural-language commands use `POST /api/assistant`; next-task suggestions use `GET /api/plan/next`; daily summaries use `GET /api/summary?date=YYYY-MM-DD`. Requests with unsupported or ambiguous intent ask for clarification instead of applying an unsafe change. The OpenAPI description is generated by FastAPI at `/docs`.
